# BHSA-derived data and audit excerpts

BHSA is produced by the Eep Talstra Centre for Bible and Computer (ETCBC),
Vrije Universiteit Amsterdam. Cite https://doi.org/10.17026/dans-z6y-skyh and
https://github.com/ETCBC/bhsa, version 2021, with the snapshot in the manifest.

The generated numeric/normalized-text features and source audit excerpts are
modified derivatives: gematria_TF extracts consonants, reconstructs specified
orthographic groups, and calculates numerical weights. These outputs retain
CC BY-NC 4.0 attribution and noncommercial terms. For commercial use consult the
rights holder identified in BHSA's README. This is separate from the new code's
MIT license and the documentation's CC BY 4.0 license.
